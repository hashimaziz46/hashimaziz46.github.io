## Problem

Drata is a security and compliance (GRC) SaaS. A full-codebase UI migration across 50+ components risked production instability if rushed, and it had to hold up under continuous deployment.

## My role

Project Manager for a 20-person team running 2-week Agile sprints, delivered through GitStart.

## What I did

- Led the full-codebase migration of 50+ UI components to custom Drata-specific components
- Designed a phased delivery strategy, migrating the least-used components first to minimize production risk
- Established a structured QA process with test case templates and a centralized issue-log dashboard
- Ran bi-weekly client review sessions to keep the backlog transparent and prioritized

## Outcome

- $840K in revenue impact delivered
- 20% increase in application speed, reported by end users
- 5% increase in testing throughput
- 10% overall efficiency gain, with ~4 hours saved per incident through centralized logging

> Least-used components first - so every risk was taken where it mattered least.
